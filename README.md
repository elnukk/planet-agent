## Wiring Convex to the Frontend

The backend schema and Convex function stubs are already written for you in `convex/`. `ConvexProvider` is already wired up in `src/app/layout.tsx` — add `NEXT_PUBLIC_CONVEX_URL` to your `.env` (run `npx convex dev` to get the value). Your job is to implement the Convex functions and replace the existing `localStorage`-based logic with real Convex queries and mutations.

### Step 1 — Implement the Convex function stubs

Open `convex/workflows.ts` and `convex/conversations.ts`. Each file has comments describing every function you need to write. Follow the same pattern as the already-implemented `convex/users.ts`:

- Import `query` / `mutation` from `"./_generated/server"` and `v` from `"convex/values"`.
- Use `ctx.db.get()` for single-row lookups, `ctx.db.query().withIndex()` for indexed lookups, `ctx.db.insert()` for creates, `ctx.db.patch()` for updates, and `ctx.db.delete()` for deletes.

---

### Step 2 — Replace `localStorage` with Convex hooks in the frontend

`src/lib/auth.ts` currently stores users and workflows in `localStorage`. Once your Convex functions are implemented, replace each `localStorage` call with the appropriate Convex hook in the component that needs the data.

**In any React component or page:**

```ts
import { useQuery, useMutation } from "convex/react";
import { api } from "../../convex/_generated/api";

// read data (live, auto-updating)
const workflows = useQuery(api.workflows.getUserWorkflows, { userId });

// write data
const createWorkflow = useMutation(api.workflows.createWorkflow);
await createWorkflow({ userId, intakeJson, notebookCells, sourceCells });
```

**Key replacements to make:**

| Current (localStorage) | Replace with (Convex) | File to update |
|---|---|---|
| `createAccount()` / `signIn()` | `createUser`, `getUserByEmail` | `src/app/page.tsx` |
| `getUserWorkflows()` | `getUserWorkflows` query | `src/app/dashboard/page.tsx` |
| Workflow load on page open | `getWorkflow` query | `src/app/workflow/[id]/page.tsx` |
| Workflow save after generation | `createWorkflow` mutation | wherever the workflow is assembled |
| Workflow edit via chat | `updateWorkflow` mutation | `src/components/workflow/ChatSidebar.tsx` |
| `softDeleteWorkflow()` | `deleteWorkflow` mutation | `src/app/dashboard/page.tsx` |
| Chat history load | `getConversation` query | `src/components/workflow/ChatSidebar.tsx` |
| Sending a chat message | `sendMessage` mutation | `src/components/workflow/ChatSidebar.tsx` |

---

### Tips

- `useQuery` returns `undefined` while loading — handle this with a loading state.
- Mutations return a `Promise` — `await` them and catch errors.
- The `api` object is auto-generated by Convex from your function files. If you add a new function, restart `npx convex dev` to regenerate it.
- You can inspect your database live in the [Convex dashboard](https://dashboard.convex.dev).
